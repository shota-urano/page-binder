# 06. 連続撮影 仕様

**親**: [`00-overview.md`](./00-overview.md) ｜ **担当**: Backend ｜ **範囲**: FR-AUTO-001～007、UC-03、requirements §8.2・§8.3

## 1. 目的

利用者が手動でページをめくる前提のもと、画面変化と安定を検知して新しい画面だけを自動保存する補助モードを提供する。**ページ送りの入力生成は行わない**（requirements §8.4）。

## 2. 入出力

- 入力: 連続撮影設定（最短間隔・最大ページ数・最大時間・感度）、撮影セッションのフレームストリーム（[04](./04-capture-session.md)）
- 出力: 保存ページ（保存自体は [05](./05-manual-capture.md) §3.1 と同じ手順を再利用）、状態表示（オーバーレイ・通知）

## 3. 処理詳細

### 3.1 状態機械（requirements §8.2）

```text
待機 → 画面変化を検出 → 安定待ち → 重複判定 → 保存 → 待機
                           └ 重複なら保存せず待機
```

### 3.2 画面変化・安定判定（requirements §8.3）

- 低解像度グレースケール画像を生成する
- 前回保存ページとの dHash または pHash 距離を計算する（ハッシュ実装は [07-image-quality](./07-image-quality.md) と共有）
- 連続する複数フレームの差が閾値以下になったら「安定」と判定する
- 時計、バッテリー表示、アニメーション等の小領域は判定対象から除外できるようにする
- 差分判定は低解像度画像で行い、端末発熱を抑える（requirements §16.1）

閾値・フレーム数の既定値は**未決事項4**（Phase 0/3 の実測で確定）。

### 3.3 保存制御

- 画面が安定し、前回保存画像との差が閾値を超えた場合のみ保存（UC-03 手順5）
- 同一・近似画面は保存せず、必要に応じて状態表示（FR-AUTO-003）
- 最短保存間隔: 初期値2秒、設定範囲1～30秒（FR-AUTO-004、UC-03 手順2）
- 最大ページ数または最大時間で自動停止できる（FR-AUTO-006）
- 検出感度は3段階で設定できる（FR-AUTO-007、Could）

### 3.4 UI・通知

- 連続撮影中であることをオーバーレイと通知に明示する（FR-AUTO-005）
- フローティングUI（連続時）: 状態表示・一時停止・停止・保存枚数（[04](./04-capture-session.md) §3.4）
- 終了はフローティング停止ボタンまたは通知から（UC-03 手順7）

## 4. 設定値・確定値

| 項目 | 値 | 出典 |
|---|---|---|
| 最短保存間隔 初期値 | 2秒 | UC-03 |
| 最短保存間隔 範囲 | 1～30秒 | FR-AUTO-004 |
| 感度段階 | 3段階 | FR-AUTO-007 |
| 差分・安定閾値の既定値 | 実装時に確定（未決事項4） | requirements §23 |
| 自動ページ送り | 実装しない（将来検討でも dispatchGesture 禁止） | requirements §8.4 |

## 5. インターフェース

- AutoCapture Use Case（domain）: 状態機械の実装。フレームストリーム購読 → 保存判断 → CaptureOnePage Use Case（[05](./05-manual-capture.md)）呼び出し
- `SettingsRepository`: 最短間隔・最大ページ数・最大時間・感度の永続化（[01-architecture](./01-architecture.md) §3.3）
- ハッシュ計算: [07-image-quality](./07-image-quality.md) の perceptual hash 実装を共有

## 6. エラー処理

- 保存失敗: 連続撮影を継続しつつ失敗を状態表示（連打起因がないため個別再試行は手動撮影と同じ導線）
- ストレージ不足: 撮影を停止し、必要容量と整理導線を表示（requirements §17）
- 最大ページ数/時間到達: 自動停止し、通知で明示

## 7. スコープ外

- 自動ページ送り（アクセシビリティサービスの目的外利用は将来検討でも禁止）
- Bluetoothリモコン等の入力生成（対象アプリ側の標準入力として扱い、本アプリは関与しない）

- [ ] [Backend] 低解像度グレースケール変換とフレーム間差分計算（除外領域対応）を実装する
  - 受け入れ基準: make verify が PASS; 同一画像で距離0、既知の異なる画像でしきい値超えとなる単体テストが通過する; 除外領域を指定すると当該領域の変化が距離へ影響しない単体テストが通過する
- [ ] [Backend] 連続撮影状態機械（変化検出→安定待ち→重複判定→保存、最短間隔・最大ページ/時間・感度3段階）を実装する
  - 受け入れ基準: make verify が PASS; フレーム列を与えた状態遷移の単体テスト（安定前に保存しない/重複をスキップ/最短間隔未満で保存しない/上限で自動停止）が通過する
- [ ] [Backend] 連続撮影設定の永続化（SettingsRepository: 間隔1～30秒・初期値2秒・最大ページ数・最大時間・感度）を実装する
  - 受け入れ基準: make verify が PASS; 初期値2秒と範囲バリデーションの単体テストが通過する
- [ ] [Frontend] 連続撮影中のフローティングUI（状態表示・一時停止・停止・保存枚数）と通知表示を実装する
  - 受け入れ基準: make verify が PASS; 連続撮影中であることがオーバーレイと通知の両方に明示される
