# 10. OCR編集画面

## 対応機能

[`../specs/09-ocr.md`](../specs/09-ocr.md) §3.5（分割表示・検索・再実行・修正・元へ戻す）

## 素材

- ソース種別: **画像** — `docs/design/mockups/10-ocr-edit.png`（実装者は必ず画像自体も見ること）
- [`00-design-overview.md`](./00-design-overview.md)「実装者への共通注意」を厳守。ページ画像・OCR本文はサンプル
- この素材は**上下分割・修正済み（編集中）**の状態

## レイアウト構造

```
アプリバー
 ├ 左: 戻る（←）
 ├ タイトル「ページ 12 のOCR」
 └ 右: 検索アイコン ・ 再実行アイコン（円弧矢印）
上ペイン: ページ画像（原寸プレビュー・薄いセピア地はサンプル画像）
 └ 右下: ズームコントロール pill「− 100% ＋」
分割ハンドル（中央・短い横バー）
下ペイン: OCRテキストカード
 ├ ステータス行: pill「修正済み」（--color-accent 系）+ 説明「元のOCR結果は保持されます」
 ├ 編集可能テキスト（本文16sp・行間広め・カーソル表示）
 └ フッター行: テキストボタン「元のOCR結果へ戻す」（左）+ Primaryボタン「保存」（右）
```

## コンポーネント一覧

| 要素 | 表示文言（画像から転記） | 状態・備考 |
|---|---|---|
| アプリバー | ページ 12 のOCR | 「12」はサンプル |
| 検索アイコン | （虫眼鏡） | ページ内検索（FR-OCR-006）。検索UI展開時の見た目は**未定** |
| 再実行アイコン | （円弧矢印） | OCR再実行。実行中表示は**未定** |
| ズーム | − 100% ＋ | 画像ペインの拡大縮小 |
| 分割ハンドル | — | **推測**: ドラッグで分割比率変更 |
| 修正済みpill | 修正済み | editedText が非null の状態表示。**未修正時の表示は未定** |
| 保持説明 | 元のOCR結果は保持されます | fullText 不変の明示（spec §3.5） |
| テキスト編集領域 | （OCR本文・サンプル） | editedText への編集 |
| 元へ戻す | 元のOCR結果へ戻す | editedText 破棄（spec §3.5）。**推測**: 確認ダイアログを挟む（破壊操作） |
| 保存 | 保存 | editedText 保存 |

## インタラクション

- 確実（spec裏付けあり）: 修正は editedText へ保存し fullText は保持 / 「元のOCR結果へ戻す」で editedText 破棄 / 再実行で OCR キューへ
- **推測**: 分割ハンドルのドラッグで比率変更 / 元へ戻す時に確認
- 未定: 画像側とテキスト側のハイライト連動（座標対応）— 素材・spec §3.5 に無し（spec §3.4 の読み順変更UIは将来スコープ）

## 未定事項

- 未修正（editedText null）時のステータス表示 — 素材なし
- ページ内検索の展開UI・ヒットハイライト — 素材なし
- OCR実行中・失敗ページを開いた場合の表示 — 素材なし
- 左右分割（横持ち等）のレイアウト — spec は「上下または左右」だが素材は上下のみ
