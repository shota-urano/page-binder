# 06. フローティングUI（オーバーレイ）

## 対応機能

[`../specs/04-capture-session.md`](../specs/04-capture-session.md) §3.4（フローティングUI基盤）、[`../specs/05-manual-capture.md`](../specs/05-manual-capture.md)（手動）、[`../specs/06-auto-capture.md`](../specs/06-auto-capture.md)（連続）

## 素材

- ソース種別: **画像** — `docs/design/mockups/06-floating-ui.png`（実装者は必ず画像自体も見ること）
- 素材は端末2台の並置: **左=手動撮影中（保存トースト表示）/ 右=連続撮影中（保存枚数表示）**
- **背面に写る読書アプリの本文・ページ表示（「12/304ページ」等）は撮影対象アプリの例示であり実装対象外**。実装するのはオーバーレイ部品と保存トーストのみ（[`00-design-overview.md`](./00-design-overview.md) 共通注意4）

## レイアウト構造

```
オーバーレイ本体（画面右端に吸着・縦長pill・地色 --color-overlay-bg）
 【手動モード（左端末）】
  ├ 撮影ボタン: 円形（56dp規定）・カメラアイコン・--color-accent のリング
  ├ 状態pill: 「📷● 撮影中」（アイコン+文字）
  └ 停止ボタン: 円形・白の停止（■）アイコン
 【連続モード（右端末）】
  ├ 状態アイコン: 円形・ビデオカメラアイコン・--color-accent のリング
  ├ 状態pill: 「▶ 連続撮影中」
  ├ 枚数pill: 「24枚」
  ├ 一時停止ボタン: 円形・⏸ アイコン
  └ 停止ボタン: 円形・■ アイコン
保存トースト（手動のみ素材あり）: 白地pill・「12 ページ目を保存しました」
```

## コンポーネント一覧

| 要素 | 表示文言（画像から転記） | 状態・備考 |
|---|---|---|
| 手動: 撮影ボタン | （カメラアイコン） | 56dp円形（system/02 規定）。1押し=1ページ |
| 手動: 状態pill | 撮影中 | 文字+アイコン併記（色だけで区別しない — requirements §16.4） |
| 手動: 停止ボタン | （■アイコン） | セッション終了 |
| 手動: 保存トースト | 12 ページ目を保存しました | 白地・黒文字・pill。「12」はサンプル値 |
| 連続: 状態pill | 連続撮影中 | ▶アイコン併記 |
| 連続: 枚数pill | 24枚 | 保存枚数カウンタ（FR系: 保存枚数表示）。「24」はサンプル |
| 連続: 一時停止 | （⏸アイコン） | |
| 連続: 停止 | （■アイコン） | |

- 地色は `--color-overlay-bg`（暗色85%）・前景 `--color-overlay-text`（トークン正本どおり）

## インタラクション

- 確実（spec裏付けあり）: ドラッグ移動可・画面端吸着（FR-CAP-006） / 撮影直前〜保存完了までオーバーレイ一時非表示（FR-CAP-002） / 通知からも停止可（FR-SES-003）
- **推測**: 保存トーストは保存完了ごとに一時表示され自動消滅
- 未定: トーストの表示位置・時間、モード切替のオーバーレイ上での可否（素材は別セッションの2態）

## 未定事項

- **停止中**状態の見た目（spec §3.4 は撮影中/停止中/連続撮影中の3状態を文字+アイコンで要求。素材は撮影中・連続撮影中のみ）
- 連続の**一時停止中**状態の見た目 — 素材なし
- ドラッグ中・吸着アニメーション — 素材なし
- 展開/折りたたみ（最小化）の有無 — 素材・specに無し
