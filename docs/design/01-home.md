## レイアウト構造

```
アプリバー（背景色のまま・影なし）
 ├ 左: アプリ名「PageBinder」（見出し・黒文字）
 └ 右: ごみ箱アイコン
検索フィールド（角丸・枠線、左に虫眼鏡アイコン）
並べ替えチップ（左寄せ・枠線pill・「更新日時順 ▼」）
書籍リスト（縦スクロール・カード型リスト行）
 └ 各行: 左サムネイル → タイトル+著者 → 右下にページ数・更新日時
FAB（右下・pill・「＋ 新しい書籍」）
```

## コンポーネント一覧

| 要素 | 表示文言（画像から転記） | 状態・備考 |
|---|---|---|
| アプリタイトル | PageBinder | |
| ごみ箱アイコン | （アイコンのみ） | ごみ箱画面（04）への導線（**推測**: タップで遷移。specs §3.3 の導線として妥当） |
| 検索フィールド | プレースホルダ「タイトル・著者で検索」 | 未入力状態のみ素材あり。検索対象=タイトル+著者部分一致（spec確定） |
| 並べ替えチップ | 更新日時順 ▼ | 既定=更新日時降順（spec）。選択肢メニュー（更新日時/作成日時/タイトル）の見た目は**未定** |
| 書籍カード行 | 例: タイトル「実践Kotlinプログラミング」/ 著者「山田太郎」/ メタ「128ページ・更新: 今日 14:32」 | サムネイル=先頭ページ画像。メタは右下寄せ・`--color-text-secondary` |
| 〃（著者なし） | 例: 「機械学習の教科書」（著者行なし） | **著者が空の行は著者行を表示しない**（画像の事実） |
| 〃（サムネイルなし） | プレースホルダ（薄地に本アイコン） | system/02 のプレースホルダ規定どおり |
| FAB | ＋ 新しい書籍 | `--color-primary` pill。タップで作成画面（02）へ（spec §3.1 手順1） |

- 更新日時の表記は相対形式の例示（「今日 14:32」「昨日」「8月20日」）。**確定仕様ではない**（要確認）

## インタラクション

- 確実（spec裏付けあり）: FAB → 書籍作成画面（02） / 行タップ → 書籍詳細画面（03）（**推測**、spec §3.1 手順3の遷移先から妥当） / 検索入力でタイトル・著者部分一致絞り込み
- **推測**: ごみ箱アイコン → ごみ箱画面（04）
- 未定: 行の長押し等のコンテキスト操作（素材・specに無し）

## 未定事項

- 空一覧（書籍0件）の表示 — 素材なし
- 検索絞り込み中・ヒット0件の表示 — 素材なし
- 並べ替えメニュー展開時の見た目 — 素材なし
- 更新日時の表記規則（相対/絶対の切替点）
