# 02. 書籍作成・編集画面

## 対応機能

[`../specs/03-book-project.md`](../specs/03-book-project.md) §3.1（作成）・§6（インラインエラー）

## 素材

- ソース種別: **画像** — `docs/design/mockups/02-book-edit.png`（実装者は必ず画像自体も見ること）
- [`00-design-overview.md`](./00-design-overview.md)「実装者への共通注意」を厳守

## レイアウト構造

```
アプリバー
 ├ 左: 戻る（←）
 └ タイトル「新しい書籍」
フォーム（縦積み・各フィールド = ラベル + 入力欄 + 下段の補助行）
 ├ タイトル（必須）: 1行入力
 ├ 著者（任意）: 1行入力
 └ メモ（任意）: 複数行入力（高さ約4行分）
保存ボタン（画面下部固定・全幅・Primary）
```

## コンポーネント一覧

| 要素 | 表示文言（画像から転記） | 状態・備考 |
|---|---|---|
| アプリバー | ← ／ 新しい書籍 | 既存書籍の編集時タイトルは**未定**（素材なし） |
| タイトル入力 | ラベル「タイトル（必須）」 | **エラー状態を素材化**: 枠 `--color-error`・下にエラー文言 |
| タイトルエラー文言 | タイトルを入力してください | 左下。右下に文字数カウンタ「0/200」 |
| 著者入力 | ラベル「著者（任意）」/ 値例「山田太郎」 | 通常状態。カウンタ「4/200」右下 |
| メモ入力 | ラベル「メモ（任意）」/ 値例「第3章まで読了。図表が多い。」 | 通常状態。カウンタ「14/2000」右下 |
| 保存ボタン | 保存 | **disabled 状態を素材化**（薄い primary・38%相当）。タイトル空のため保存不可（spec §6） |

- 文字数上限（200/200/2000）は spec §4 の確定値と一致
- カウンタは全フィールドで常時表示（画像の事実）

## インタラクション

- 確実（spec裏付けあり）: タイトル空・文字数超過で保存不可+インラインエラー / 保存成功で書籍詳細画面（03）へ遷移（spec §3.1 手順3）
- **推測**: ← タップで保存せず戻る（破棄確認の有無は未定）
- 未定: 入力中のリアルタイムバリデーションのタイミング（フォーカスアウト時/入力毎）

## 未定事項

- 既存書籍の**編集モード**（アプリバータイトル・初期値入り表示）— 素材なし。spec §3.4「書籍設定」の遷移先
- 文字数**超過**時のエラー表示 — 素材なし（空エラーのみ素材化）
- 未保存で戻る際の破棄確認 — 素材・specに無し
