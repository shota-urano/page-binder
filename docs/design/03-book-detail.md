## レイアウト構造

```
アプリバー
 ├ 左: 戻る（←）
 ├ タイトル: 書籍タイトル（例「実践Kotlinプログラミング」）
 └ 右: 鉛筆アイコン
書籍情報カード: タイトル（見出し）+ 著者 + メモ
統計カード（2×2 グリッド・縦横の区切り線）
 ├ ページ数 / OCR完了（チェックアイコン付き）
 └ エラー / 使用容量
撮影ボタン行（横並び2つ）
 ├ 手動撮影を開始（Primary 塗り）
 └ 連続撮影を開始（Secondary 枠線）
導線リストカード（4行・各行にシェブロン「>」・行間区切り線）
 ├ ページ一覧
 ├ OCR一括実行
 ├ 書き出し
 └ 書籍設定
```

## コンポーネント一覧

| 要素 | 表示文言（画像から転記） | 状態・備考 |
|---|---|---|
| 鉛筆アイコン | （アイコンのみ） | **推測**: 書籍編集（02）への導線。下段「書籍設定」と重複する可能性 → 要確認 |
| 統計: ページ数 | ページ数 / 例「128」 | 数値は大きめ（見出しサイズ） |
| 統計: OCR完了 | OCR完了 / 例「✓ 96」 | チェックアイコン `--color-accent` |
| 統計: エラー | エラー / 例「2」 | 数値 `--color-error`。0件時の色は**未定** |
| 統計: 使用容量 | 使用容量 / 例「245 MB」 | |
| 手動撮影開始 | 手動撮影を開始 | Primary。→ 撮影準備画面（05）（spec §3.4） |
| 連続撮影開始 | 連続撮影を開始 | Secondary。→ 撮影準備画面（05・連続選択） |
| 導線行 | ページ一覧 / OCR一括実行 / 書き出し / 書籍設定 | 各行右端にシェブロン。遷移先: 07 / OCRキュー投入（09） / 11 / 02（編集モード） |

- spec §3.4 の導線6つ（手動・連続・ページ一覧・OCR一括・書き出し・書籍設定）はすべて素材に存在

## インタラクション

- 確実（spec裏付けあり）: 撮影2ボタン → 撮影準備（05） / ページ一覧 → 07 / 書き出し → 11 / 書籍設定 → 02 編集モード
- **推測**: OCR一括実行はタップで即キュー投入（確認ダイアログの有無は未定） / 鉛筆 = 書籍設定と同じ編集導線
- 未定: 書籍の削除操作の置き場所（この画面には見当たらない。ホームまたは編集画面側か — 要確認）

## 未定事項

- ページ0件（撮影前）の統計・導線の表示 — 素材なし
- OCR一括実行タップ時のフィードバック（確認・トースト等）— 素材なし
- 削除（ごみ箱へ送る）導線の位置 — 素材のどの画面にも明示なし（04 はごみ箱内の操作のみ）
