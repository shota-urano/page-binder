# 07. ページ一覧画面

## 対応機能

[`../specs/08-page-editing.md`](../specs/08-page-editing.md) §3.1（一覧）・§3.2（複数選択・削除・警告）

## 素材

- ソース種別: **画像** — `docs/design/mockups/07-page-list.png`（実装者は必ず画像自体も見ること）
- [`00-design-overview.md`](./00-design-overview.md)「実装者への共通注意」を厳守
- この素材は**グリッド表示・複数選択モード（2件選択中）**の状態。サムネイル内の本文・「接続を確認しています…」等はサンプル

## レイアウト構造

```
選択モードアプリバー（--color-primary 塗り・白文字）
 ├ 左: 「2件を選択中」
 └ 右: ごみ箱アイコン ・ ×（選択解除）
ツールバー行
 ├ 左: 表示切替トグル（グリッド | リスト）— アイコンボタン、選択側に枠
 └ 右: 並び順「ページ順 ▼」
サムネイルグリッド（3列・8dp間隔 — トークン規定）
 └ 各セル: 上に連番（1,2,3…）・サムネイルカード・下部に状態バッジ
    選択中セル: 左上にチェック円（primary）+ primary 枠線
```

## コンポーネント一覧

| 要素 | 表示文言（画像から転記） | 状態・備考 |
|---|---|---|
| 選択モードバー | 2件を選択中 / ごみ箱アイコン / × | 件数は動的。通常時（非選択）のアプリバーは**未定** |
| 表示切替 | （グリッド/リストアイコン） | 素材はグリッド選択。リスト表示の見た目は**未定** |
| 並び順表示 | ページ順 ▼ | **推測**: 表示順の切替メニュー。spec §3.1 は sequence 順表示+ドラッグ並べ替えのみ → 選択肢は要確認 |
| ページ連番 | 1〜9 | セル左上外側・sequence |
| OCR状態バッジ: 完了 | ✓ 完了 | `--color-accent`（system/02 の succeeded） |
| 〃: 実行中 | ↻ 実行中 | `--color-primary`（running） |
| 〃: 失敗 | ❗ 失敗 | `--color-error`（failed） |
| 警告バッジ: 重複 | ⚠ 重複 | `--color-warning` |
| 警告バッジ: 黒画面 | ⚠ 黒画面 | `--color-warning`。黒サムネイルの例に付与 |
| 選択チェック | （チェック円） | 選択セルは primary 枠 |

- バッジはすべて**アイコン+文字併記**（requirements §16.4、system/02 準拠）
- 「待機（pending）」「再実行が必要（stale）」バッジは素材に**写っていない**が、system/02 の規定（時計+待機 / 更新+再実行が必要）に従う

## インタラクション

- 確実（spec裏付けあり）: グリッド/リスト切替（FR-EDT-001） / 複数選択→ごみ箱アイコンで削除（削除確認に件数表示、spec §6） / ドラッグで並べ替え（FR-EDT-002）
- **推測**: セルタップ=通常時は編集画面（08）へ、選択モード中は選択トグル / 長押しで選択モード開始
- 未定: 重複・黒画面バッジのタップで確認画面（09）へ遷移するか

## 未定事項

- **リスト表示**の見た目 — 素材なし
- **通常時（非選択）のアプリバー**（画面タイトル・戻る・09への導線）— 素材なし
- **削除確認ダイアログ** — 素材なし（04 のダイアログ様式踏襲が推測。件数を必ず表示）
- 待機・stale バッジの実表示 — 素材なし（system/02 の規定に従う）
- ドラッグ並べ替え中の見た目 — 素材なし
- 500ページ時のスクロール補助（インデックス等）— 素材・specに無し
