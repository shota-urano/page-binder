[`../specs/11-export.md`](../specs/11-export.md) §3.2（書き出しフロー）、[`../specs/12-legal-guardrails.md`](../specs/12-legal-guardrails.md) §3.2（権限確認）

## 素材

- ソース種別: **画像** — `docs/design/mockups/11-export.png`（実装者は必ず画像自体も見ること）
- [`00-design-overview.md`](./00-design-overview.md)「実装者への共通注意」を厳守。ファイル名・件数はサンプル
- この素材は**形式選択+OCR未完了警告あり+権限確認チェック済み**の状態

## レイアウト構造

```
アプリバー: ←「書き出し」
出力形式カード: 見出し「出力形式」+ ラジオ5択（縦積み）
設定カード
 ├ 見出し「設定」
 ├ ファイル名: アウトライン入力（ラベル埋め込み型）
 ├ ページ範囲: ラベル+値+▼（ドロップダウン行）
 └ PDF画質: ラベル+値+▼
警告バナー（--color-warning 系薄地・角丸）: ⚠ + 文言 + 右端アクション「確認」
利用上の注意カード
 ├ 見出し「利用上の注意」
 ├ 説明文
 └ チェックボックス（権限確認）
書き出しボタン（画面下部・全幅・Primary）
```

## コンポーネント一覧

| 要素 | 表示文言（画像から転記） | 状態・備考 |
|---|---|---|
| 出力形式ラジオ | 検索可能PDF / 画像PDF / Markdown / テキストZIP / 画像ZIP | 素材は検索可能PDF選択。spec §3.1 の5形式（searchable_pdf / image_pdf / markdown / text_zip / image_zip）と1対1 |
| ファイル名 | ラベル「ファイル名」/ 値例「実践Kotlinプログラミング」 | 初期値=書籍タイトル（**推測**） |
| ページ範囲 | ページ範囲 / 例「すべて (1〜128)」▼ | ページ範囲指定はMVP確定（spec §3.2）。**範囲指定の入力UIは未定** |
| PDF画質 | PDF画質 / 例「標準」▼ | 選択肢は「高画質/標準/軽量」の3段階・既定は「標準」（**2026-08-27 ユーザー確定**） |
| OCR未完了警告 | OCRが完了していないページが3件あります / アクション「確認」 | FR-EXP-009。件数は動的。「確認」の遷移先は**推測**: 該当ページ一覧（07 か 09） |
| 利用上の注意 | 書き出した成果物の取り扱いは利用者の責任で確認してください | |
| 権限確認チェック | この成果物を利用する権限を確認しました | **文言は spec 12 §3.2 の確定文言と一致（言い換え禁止）**。チェックなしで書き出し不可 |
| 書き出しボタン | 保存先を選んで書き出す | タップで SAF 保存画面へ（共有ボタンは設けない — spec §3.3） |

## インタラクション

- 確実（spec裏付けあり）: チェックなしで書き出し開始不可 / OCR未完了時は警告し続行/中止を選べる / ボタン → SAF Document Provider 選択 → 一時出力→確定
- **推測**: 非PDF形式選択時は「PDF画質」行を非表示または無効化
- 未定: 「確認」アクションの遷移先 / 警告がある状態で続行する操作の形（この画面のボタンで続行か、追加確認か）
