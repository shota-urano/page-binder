# 08. 回転・切り取り編集画面

## 対応機能

[`../specs/08-page-editing.md`](../specs/08-page-editing.md) §3.2（回転・切り取り）・§3.4（取り消し）、[`../specs/07-image-quality.md`](../specs/07-image-quality.md)（非破壊編集）

## 素材

- ソース種別: **画像** — `docs/design/mockups/08-page-edit.png`（実装者は必ず画像自体も見ること）
- [`00-design-overview.md`](./00-design-overview.md)「実装者への共通注意」を厳守
- この素材は**crop 編集中**の状態。ページ画像の内容（機械学習の教科書）はサンプル

## レイアウト構造

```
アプリバー
 ├ 左: ×（閉じる）
 ├ タイトル「ページ 12 を編集」
 └ 右: テキストボタン「保存」（--color-primary）
編集キャンバス（暗色地・--color-overlay-bg 系）
 ├ ページ画像（中央）
 ├ crop 枠: --color-accent の線 + 白丸ハンドル8個（四隅+四辺中央）
 ├ crop 外領域: 灰色の減光
 └ キャンバス下端キャプション「元の画像は変更されません」（白文字）
操作エリア（明色地）
 ├ ボタン行（横並び2つ・枠線ボタン）: 「↻ 90°回転」「↩ 元に戻す」
 └ チェックボックス行「この書籍の全ページに同じ切り取りを適用」
```

## コンポーネント一覧

| 要素 | 表示文言（画像から転記） | 状態・備考 |
|---|---|---|
| アプリバー | × / ページ 12 を編集 / 保存 | 「12」はサンプル（sequence） |
| crop 枠 | — | ハンドル8個ドラッグで範囲編集（FR-EDT-005） |
| 非破壊の明示 | 元の画像は変更されません | FR-IMG-007 の利用者向け明示 |
| 90°回転 | 90°回転（回転アイコン付き） | 90度単位（FR-EDT-004） |
| 元に戻す | 元に戻す（戻るアイコン付き） | 直前1操作の取り消し（spec §3.4 確定） |
| 一括適用 | この書籍の全ページに同じ切り取りを適用 | チェックボックス。素材は**未チェック** |

## インタラクション

- 確実（spec裏付けあり）: 保存で rotation / crop を非破壊保存 → 該当ページの ocrState が stale 化（spec §3.3） / 一括適用チェックで同一書籍全ページへ同じ crop（FR-IMG-005/006）
- **推測**: × は変更を破棄して閉じる（破棄確認の有無は未定） / 回転はプレビューへ即時反映
- 未定: 一括適用チェック時の確認ダイアログ（全ページ stale 化の影響が大きい — 要確認）

## 未定事項

- 回転適用後の表示 — 素材なし
- 一括適用を有効にして保存する際の確認 — 素材・specに無し
- ピンチズーム等のキャンバス操作 — 素材に無し
- 縦長画像・横長画像でのレイアウト差 — 素材は縦のみ
