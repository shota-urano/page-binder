## コンポーネント一覧

| 要素 | 表示文言（画像から転記） | 状態・備考 |
|---|---|---|
| アプリ名 | PageBinder | |
| タグライン | 画面を撮って、検索できる本棚に。すべて端末の中だけで。 | |
| カード見出し | ご利用の前に | |
| 同意事項1 | 正当に閲覧できるコンテンツのみを対象にしてください | spec §3.1 の1点目に対応 |
| 同意事項2 | 複製や外部サービスへの入力の可否は、ご自身で確認してください | 2点目に対応 |
| 同意事項3 | 撮影が禁止・保護されている画面を回避する機能はありません | 3点目に対応 |
| 同意事項4 | 出力物を無断で配布しないでください | 4点目に対応 |
| 同意ボタン | 同意して始める | 同意日時・文言バージョンを保存（spec §3.1） |
| 非同意ボタン | 同意しない | 主要機能へ進めない（spec）。**タップ後の見た目は未定** |

- spec は「表示文言の確定は実装時（4点を必ず含む）」。モックの文言は4点をすべて満たしており、**この転記文言を実装文言の初版とする**（法務系文言のためデザイン側で言い換えない — system/03。変更時は spec 側の判断）

## インタラクション

- 確実（spec裏付けあり）: 同意して始める → 同意履歴保存 → ホーム（01）へ / 未同意では主要機能へ進めない（ナビゲーションガード）
- 未定: 「同意しない」タップ後の挙動（アプリ終了か・この画面に留まるか — spec も画面表現を定めていない）

## 未定事項

- 「同意しない」選択後の表示 — 素材・specに無し（要確認）
- 文言バージョン改定時の再同意画面（同一デザイン流用が推測）
- スクロールが必要な小画面での挙動 — 素材は1画面収まりのみ
