# 06. フローティングUI（オーバーレイ） — A用プロンプト

- **対象**: フローティングUI基盤 ｜ spec: [`04-capture-session.md`](../../../specs/04-capture-session.md) §3.4（手動: [05](../../../specs/05-manual-capture.md)・連続: [06](../../../specs/06-auto-capture.md)）
- **生成順**: 6（基準画面 = 01 ホーム画面とトーン・配色を揃える）
- **含める状態**: 手動モード（撮影中）と連続モード（保存枚数表示）の2バリエーションを1枚に並べる

## スタイルアンカー（共通ブロック・全A用ファイル逐語一致）

トーン: 誠実・実用・静か。装飾より情報。プライバシー重視のオフラインツールとしての信頼感を、ロゴ由来のフレンドリーな丸みで和らげる。
配色: primary ロイヤルブルー #1E3FAE / accent ミント #2DD4A8 / 背景 #F8FAFC / サーフェス #FFFFFF / 本文 #1A2233 / 補助テキスト #5B6472 / 区切り線 #E2E8F0 / エラー #DC2626 / 警告 #D97706 / 成功 #16A34A
タイポ: システムサンセリフ（Roboto / Noto Sans JP）。見出し22sp・画面タイトル18sp・本文16sp・補助14sp・キャプション12sp。
角丸: カード12dp・ボタン8dp・FAB/チップ/バッジはpill。影は控えめ。
密度: 中密度。リスト行72dp・グリッド3列・左右マージン16dp・8dpグリッド。
デバイス: Androidスマートフォン縦持ち・アスペクト比9:19.5・Material 3ライトテーマ。ステータスバーとナビゲーションを含む実機フレームで描く。

## 画面固有

- 地色は暗色半透明 #1A2233 @85%・白文字（他アプリ上での視認性のため。ライトテーマの例外）
- 状態は色だけでなく**文字とアイコン**で区別（requirements §16.4）
- 画面端に吸着したpill形。背景には他アプリ（電子書籍リーダー風の本文ページ）を敷く
