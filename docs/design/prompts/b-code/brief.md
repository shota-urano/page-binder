# PageBinder — デザインプロトタイプ依頼ブリーフ

（このファイル1枚を Claude design の新規セッションに丸ごと貼ってください）

## やりたいこと

**PageBinder** は、スマホの画面を撮影して書籍単位で整理し、端末内OCRで検索可能なPDFにする、
**完全オフライン**の Android アプリ（個人利用）。ネットに一切つながらないことが最大の価値。

トーン: **誠実・実用・静か**。装飾より情報。プライバシーを守るツールとしての信頼感を、
ロゴ由来のフレンドリーな丸み（ブルー×ミント）で和らげる。マーケティング的な演出はしない。
日本語UI・です/ます調・Android スマートフォン縦持ち基準。

このブリーフに書いていないレイアウト・装飾・細部の表現は、**雰囲気に合う範囲で自由に**提案してください。

## 要約デザインシステム（コアパレットのみ）

- primary: ロイヤルブルー `#1E3FAE`（主要アクション・選択状態）
- accent: ミント `#2DD4A8`（完了・進捗の強調）
- background: `#F8FAFC` / surface: `#FFFFFF` / text: `#1A2233`
- error: `#DC2626` / warning: `#D97706`（重複・黒画面・OCR未完了の警告）
- フォント: システムサンセリフ（Roboto / Noto Sans JP）。ライトテーマのみ
- 方針: 状態は色だけで区別せず**アイコン+文字**を併記。破壊操作は対象の件数・容量を見せて確認

## 出力形式

- **複数画面を含む単一プロトタイプ（1アプリ）でよい**。画面間はナビゲーションで遷移できると理想
- **README に「画面 → コンポーネント/ファイルの対応表」を必ず含めてください**（画面単位で採用判定するため）
- 依存は最小に。重い表現（実画像など）はプレースホルダで構いません
