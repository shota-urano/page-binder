## レイアウト構造

```
アプリバー: ←「確認が必要なページ」
重複カード
 ├ 見出し行: 「重複の候補 (1組)」+ 右端に「重複」pill（--color-warning）
 ├ 比較ペア（横並び2枚）: プレビュー画像 + 「ページ 7」/「ページ 8」
 │  └ 各下に選択ボタン「このページを残す」（選択側: チェック付き・primary 枠強調 / 非選択側: 通常枠線）
 └ 注記（右寄せ・補助色）: 「選ばなかったページは削除候補になります」
黒画面カード
 ├ 見出し行: 「黒画面の候補 (2件)」+「黒画面」pill
 └ 候補行（縦積み）: 黒サムネイル + 「ページ 15」+ 説明文
    右端にテキストボタン「削除」（--color-error）｜区切り｜「残す」（--color-primary）
```

| 重複注記 | 選ばなかったページは削除候補になります | |

| 行アクション | 削除 ｜ 残す | 削除=`--color-error`、残す=`--color-primary` のテキストボタン |

## インタラクション

- 確実（spec裏付けあり）: 重複ペアから残すページを選ぶと他方が削除候補になる（FR-EDT-006・spec 実装単位の受け入れ基準どおり） / 黒画面候補は個別に削除/残すを選べる（FR-EDT-007）
- **推測**: 「削除」タップで確認（件数・破壊操作の確認原則から）→ 実行 / 全件処理後は前画面へ戻る
- 未定: 重複の「削除候補」が確定削除になるタイミング（即時か・確認画面経由か）

## 未定事項

- 候補0件時の表示（画面自体を出さないか、空表示か）— 素材なし
- 削除実行時の確認ダイアログ — 素材なし（04 様式踏襲が推測）
- 3枚以上の重複組の表示 — 素材は2枚ペアのみ
- この画面への遷移導線 — 素材・specとも明示なし（要確認）
