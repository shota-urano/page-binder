# 05. 撮影準備画面

## 対応機能

[`../specs/04-capture-session.md`](../specs/04-capture-session.md) §3.2（権限フロー・準備画面）

## 素材

- ソース種別: **画像** — `docs/design/mockups/05-capture-prep.png`（実装者は必ず画像自体も見ること）
- [`00-design-overview.md`](./00-design-overview.md)「実装者への共通注意」を厳守
- この素材は**オーバーレイ未許可（撮影開始が無効）**の状態

## レイアウト構造

```
アプリバー: ←「撮影の準備」
保存先カード: ラベル「保存先」+ 書籍タイトル
撮影方式カード
 ├ 見出し「撮影方式」
 ├ セグメントトグル（手動 | 連続）— 選択側が primary 塗り
 └ 設定サマリ行（薄地・3分割）: 最短間隔 / 最大ページ数 / 最大時間
必要な許可カード
 ├ 見出し「必要な許可」
 ├ 行1: 警告アイコン + 権限名 + 状態チップ + アクションボタン + 説明文
 └ 行2: 情報アイコン + 権限名 + 説明文
画面下部: 無効理由テキスト + 撮影開始ボタン（全幅・disabled）
```

## コンポーネント一覧

| 要素 | 表示文言（画像から転記） | 状態・備考 |
|---|---|---|
| 保存先 | 保存先 / 例「実践Kotlinプログラミング」 | |
| 撮影方式トグル | 手動 ｜ 連続 | 素材は「手動」選択（primary塗り+白文字） |
| 連続設定サマリ | 最短間隔 2秒 / 最大ページ数 200 / 最大時間 30分 | 2秒=spec初期値。**200・30分はspecに初期値の定めなし=サンプル値**（要確認）。※素材では手動選択中もこの行が見えている（要確認） |
| オーバーレイ権限行 | 他のアプリの上に表示 + チップ「未許可」+ ボタン「設定を開く」 | 警告アイコン `--color-warning`。チップは warning 系薄地 |
| 〃 説明文 | 撮影ボタンを画面に重ねて表示するために必要です | 権限要求前の理由説明（requirements §16.4） |
| 画面共有説明行 | 画面共有の許可 | 情報アイコン `--color-primary`。状態チップなし（セッションごとにOS画面で許可のため） |
| 〃 説明文 | 撮影開始時に毎回、Androidの確認画面が表示されます。この端末の画面だけを取得し、外部には送信しません | |
| 無効理由 | オーバーレイ許可が必要です | 開始ボタン直上・中央 |
| 撮影開始ボタン | 撮影開始 | **disabled 状態を素材化**。オーバーレイ未許可時は開始不可（FR-SES-007） |

## インタラクション

- 確実（spec裏付けあり）: 「設定を開く」→ OS設定（オーバーレイ許可）へ / 許可済みになると撮影開始が有効化 / 撮影開始 → MediaProjection のOS確認 → フローティングUI（06）
- **推測**: トグル切替で連続設定サマリの表示/内容が変わる
- 未定: 連続設定（間隔1〜30秒等）の**変更UI**（この画面かどうか・入力形式とも素材に無い）

## 未定事項

- 許可済み状態（チップ・ボタンの見た目、開始有効時）— 素材なし
- `POST_NOTIFICATIONS`（通知権限）の行 — spec §3.2 にはあるが**素材に無い**（要確認）
- 連続撮影設定の変更UI・最大ページ数/最大時間の初期値 — 素材はサンプル値のみ
- 手動選択時に連続設定サマリを表示するか — 素材とspecの含意が食い違う可能性（要確認）
