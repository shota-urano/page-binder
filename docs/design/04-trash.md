# 04. ごみ箱画面

## 対応機能

[`../specs/03-book-project.md`](../specs/03-book-project.md) §3.3（削除・ごみ箱・完全削除の確認）

## 素材

- ソース種別: **画像** — `docs/design/mockups/04-trash.png`（実装者は必ず画像自体も見ること）
- [`00-design-overview.md`](./00-design-overview.md)「実装者への共通注意」を厳守
- この素材は**完全削除の確認ダイアログ表示中**の状態（背面にスクリム）。全画面の削除確認ダイアログ様式の見本を兼ねる

## レイアウト構造

```
画面タイトル「ごみ箱」（大見出し・左上）
説明文（タイトル直下・補助色）
ごみ箱リスト（カード型リスト行）
 └ 各行: 左プレースホルダサムネイル → タイトル + メタ（ページ数・残り日数）
          行右下にテキストボタン「復元」「完全に削除」
—— ダイアログ（モーダル・スクリム越し）——
 タイトル / 本文（対象・件数・容量・不可逆の明記）/ キャンセル + 実行ボタン
```

## コンポーネント一覧

| 要素 | 表示文言（画像から転記） | 状態・備考 |
|---|---|---|
| 画面タイトル | ごみ箱 | 戻る矢印が**素材に見えない** → ナビゲーション表現は未定（要確認） |
| 説明文 | 削除した書籍は30日間保持されます | spec確定値30日と一致 |
| ごみ箱行 | 例: 「古いレシピメモ」/「12ページ・残り 24日」 | サムネイルはプレースホルダ（本アイコン） |
| 復元ボタン | 復元 | テキストボタン・`--color-primary` |
| 完全削除ボタン | 完全に削除 | テキストボタン・`--color-error` |
| ダイアログタイトル | 完全に削除しますか? | |
| ダイアログ本文 | 『古いレシピメモ』（12ページ・28 MB）を完全に削除します。この操作は取り消せません。 | **対象名+ページ数+容量を必ず含める**（spec §3.3 手順1・system/02 ダイアログ規定） |
| ダイアログボタン | キャンセル（テキスト・primary色）/ 完全に削除（`--color-error` 塗り・白文字） | Destructive は赤塗り |

## インタラクション

- 確実（spec裏付けあり）: 完全に削除 → 確認ダイアログ → 実行で物理削除 / 復元 → 通常一覧へ戻す（deletedAt解除）
- **推測**: 復元はダイアログなしの即時実行（素材に復元確認は無い。破壊操作でないため妥当だが未確認）
- 未定: ごみ箱行タップ時の挙動（詳細閲覧できるか）

## 未定事項

- 空のごみ箱の表示 — 素材なし
- この画面への戻り導線（アプリバー・戻る矢印が素材に無い）
- 復元時の確認・完了フィードバック — 素材なし
